## 2. Product and boundaries

k-lani-link is self-hosted software that authenticates peers and encrypts and
transports supported AI API requests and responses between two computers chosen
by the operator. It includes streaming and documented concurrency limits. Optional
model management starts and stops pre-approved local model processes. It does not
allow arbitrary remote commands or model paths supplied by an inference client.

k-lani-link does not itself generate AI answers or execute model-suggested file
changes, shell commands or tool calls. Those actions depend on the connected
model, coding agent, harness, tools and operator-granted permissions. The supplier
does not promise a particular accuracy, security or commercial usefulness of
third-party AI output. Responsibility for the supplier's own breaches or defects
in k-lani-link remains unaffected.

The purchase includes no model weights, compute, hosted inference or TURN service.
TURN requires explicit configuration of a separately obtained service. Internet access alone does not guarantee connectivity. NAT, firewalls, proxies,
endpoint protection and network policy can prevent direct connections. Operation
in every network is not promised. Responsibility for defects in the supplier's
own software remains unaffected. The agreed product description,
system requirements and limitations disclosed before purchase determine the scope.
The reference deployment is currently tested on Linux x86_64 with Docker; native
Windows and macOS packages have not been released. The Basalt adapter requires a
supported NVIDIA GPU and appropriate local model weights.
