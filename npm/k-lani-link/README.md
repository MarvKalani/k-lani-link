# k-lani-link

Use the AI models on your own computers from anywhere, end-to-end encrypted.

```sh
npm install -g k-lani-link
```

First start:

```sh
k-lani-link                          # opens the control panel in your browser
k-lani-link --help                   # lists all commands
npm install -g k-lani-link@latest    # updates it; npm does not do this by itself
```
