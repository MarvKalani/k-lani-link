                  Updates
                  
        
        
                  Twice a day, k-lani-link asks GitHub whether a newer version exists; only its own version number goes along. A new version must carry the k-lani-link signature. It is downloaded and installed at the next start.
                  
      
                  
      
                  If it does not connect
                  
      
                    
        
                  • Waiting a long time: k-lani-link must be running on the model computer (“host”).
                    • 
        
                  • Code not accepted: each code works once. Ask for a new one.
                    • 
        
                  • Access refused: the access for this computer expired or was withdrawn. Ask for a new code.
                    • 
        
                  • No model: a model must be loaded on the model computer.
                    • 
        
                  • Port occupied: another k-lani-link client is already running on this computer.
                    • 
        
                  • Relay full: the relay allows this access only a few connections at once, and they are in use. End another one, or ask its operator for a higher limit.
                    •
