# Recorded English business workflow

The optional Craft profile in [README.md](README.md) prepares local WordCraft and
GridCraft MCP tools. Inputs are in `examples/business-demo/`; `prepare-demo.py`
creates an empty output directory and never pre-generates the deliverables.

The recorded run produced an invoice as DOCX/PDF, a formula-based ledger as
XLSX/HTML, and an English project website with the supplied artwork under the former product name.
All customer information is synthetic. The original accepted files are archived
privately. The documents in `website/` remain unchanged; the page name and artwork
were subsequently updated for k-lani-link. Its provenance file separates those edits.

Codex acted as the operator: environment setup, prompts, six visible follow-up
instructions, read-only validation and video assembly. The local Basalt model
performed the document and code changes through OpenCode. Earlier failed edits,
missing metadata and the two-page draft were corrected by the same local agent,
not replaced with operator-written outputs. This is not an unattended workflow.

The [public archive edit](../../assets/demo/README.md) selects document-workflow
excerpts and original document previews. Former name overlays and provider badges
are masked; English title cards identify the historical run and operator's role.
The original website-generation footage remains private because it contains the
former name throughout its prompts and generated code. The public edit is not a
new recording of website generation or a new benchmark.

The private recording directory is `recordings/2026-10-27-opencode-business/`.
The run crossed midnight in Europe/Berlin. The short video consists of labelled,
chronological excerpts plus labelled static previews. The long video preserves
the elapsed capture timeline. Browser screenshots have timestamps; capture gaps
hold the previous image and are marked. Four output frames per second do not
mean that every source moment was captured. There is no audio or speed-up within
the excerpts. Raw manifests and resource CSV/JSON files accompany the video.

Operator screenshots were visible to Codex, so synthetic data was essential.
The network checks establish the isolation of the application/backend containers,
not a cloud-free operator environment or automatic GDPR compliance.

The lab shares one model and one tunnel. Background requests such as automatic
session titles can temporarily encounter the MVP's single-active-request limit;
OpenCode retried this during the website session. Do not run ThinkRail and
OpenCode inference tasks concurrently on this peer.

The source bundle excludes private recordings, keys, model weights and runtime
state. It includes only the explicitly reviewed synthetic website downloads.
The project now uses [BSL 1.1](../../LICENSE). Selected, reviewed synthetic demo
clips may accompany a public release; private runtime files and full capture
archives are excluded from the source bundle.
