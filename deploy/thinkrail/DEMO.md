# ThinkRail and the public k-lani-link demo

The current public recording is the [English OpenCode/Basalt business workflow](../opencode/DEMO.md):
a fictional invoice, PDF, spreadsheet and website. Its accepted outputs are
preserved byte-for-byte in [website/](../../website/README.md).

The earlier ThinkRail website experiment included direct operator edits and is
kept with the local development recordings. Its superseded prompts and setup
helper are no longer part of the current public source. This does not change
the provenance of the accepted OpenCode demonstration.

To run ThinkRail itself, use [the isolated nightly setup](README.md).
For a fresh recording, explicitly start the numeric resource collector, record
only synthetic data, and review the footage before publishing. Recording and video-assembly helpers are maintainer tools, outside the current
source package. The public clips and their provenance remain available.
