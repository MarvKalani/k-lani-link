using local Basalt Coder through the encrypted peer connection**. Codex prepared
the environment, supplied briefs and six visible follow-ups, reviewed the output
and assembled the video. The original accepted files were copied byte-for-byte.

## What the original run demonstrates

Basalt used local WordCraft 0.11.0 / GridCraft 0.12.1 MCP tools to create the
DOCX/PDF invoice and XLSX/HTML ledger, then generated the website. Earlier mistakes
and operator follow-ups remain in the private recording. This was an assisted
workflow, not unattended single-prompt success.

Codex could view synthetic screen content as the external operator. The recording
therefore does not establish that the operator's entire desktop was cloud-free.
Network isolation checks cover the test containers; the agent's configured
inference provider was the local Basalt endpoint.

Both peers ran on one machine. TURN was disabled, signaling stopped after pairing,
and swap was disabled. The Coder pack was read from RAID 0. The 256K context window
was configured, not filled by this test. No Internet latency or RAID throughput
benchmark is claimed.

The PDF has one A4 page and the spreadsheet totals are EUR 1,280 net + EUR 256
illustrative tax = EUR 1,536 gross. Previous browser rendering was checked at
770/1280 pixels; a mobile viewport was not independently verified.
